# 对抗性演示，以及它不是什么 / The adversarial showcase, and what it is not

> **本文件是 `D48 ③` 要求的那份边界声明。** 它说明这个展示是什么、刻意不是什么，以及参照实现的哪几条
> 场景在这里**没有可落的东西**。
>
> **This file is the boundary declaration `D48 ③` requires.** It says what the showcase is, what it
> deliberately is not, and which of the reference's scenarios have nothing to land on here.

## 它是什么

宿主自己控制台里的一个页面，背后两条路由（`GET /ai/security-showcase/scenarios`、
`POST /ai/security-showcase/run/{id}`），每条都**对着本部署**跑——这个运行时、宿主的这些工具、宿主解析
出来的那个身份。每条场景报的是**运行时自己的答复**，并把**引擎的原始状态**一并带回来，故这里**没有**
任何被发明出来的词表：工具说「不」而引擎把它叫 `error` 的一次拒绝，会**既**作为一次拒绝显示、**也**带上
引擎对它的叫法。

运行器只从**所有提议都会走的那一个入口**（`execute`）**驱动**引擎。它自己**不实现**任何门、任何确认策略、
任何范围规则——那些留在 `keelbase4j-core` 里，这也是它能存在于宿主上、而不把边界搬到宿主上的原因。它与
本线**已经养着**的那些场景门禁（`scripts/run-*-scenarios.mjs`）是同一形状。

## 它刻意不是什么

**它是 runtime-specific 的展示物：没有 wire 对象，也不在 replay 范围。** 契约仓里没有任何东西描述它——
不在 schema 里（`v1`–`v5` 都没有），也不在参照实现自己的场景语料里；那份语料**对自己**是这么说的：五个
用例「没有对应的 wire 对象」，被排除在中立重放之外，因为它们打的是某一个实现自己的路由。

故本页对**跨运行时可比性**没有任何贡献，这里的任何东西也不该被引作契约符合性。它提供的是一件演示能提供
的事：一个**当着人**看**本部署**拒绝东西的办法。

## 四条场景，不是参照实现那五条

| id | 驱动什么 | 期望 |
|---|---|---|
| `unauthorized` | 一次调用方做不了的读 | 工具拒绝它 |
| `confirmation` | 一次 R3 写（本运行时扣下等人） | 被扣下、带回一个 token；**什么都没写** |
| `unknown-tool` | 一个不存在的工具名 | 登记处拒绝解析它 |
| `positive-control` | 一次调用方做得了的读 | 它跑通并返回数据 |

最后那条不是点缀。**没有它**，「一律拒绝」能通过上面每一条。

**参照实现那五条里，有两条在这里没有可落的东西，而且没有替它们编一个：**

- **R5 阻断。** 本运行时的门**只看风险级**（`R5 → block`）；它没有策略开关、没有角色白名单，而本部署也
  **没有声明任何 R4/R5 工具**。**没有**一个能被阻断的工具，**也没有**一条能阻断它的策略。要让这条场景落地，
  需要一个那一档的工具——或者一个本运行时**并不具备**的策略面。
- **提示词注入。** 这条路径上**没有提示词**。本部署的规划器是**规则版**，故一次注入**没有可注入的地方**。
  要让它落地，需要一条**模型路径**。

## `unauthorized` 那条证明了什么、没证明什么

它用一个**合成** id 去驱动 `get_notify_message`，而这是**忠实**、不是走捷径：那个工具对「不是你的」与
「不存在」回**同一句话**——两者它**一概扣下**——故一个在调用方范围外的 id，走的是**与真外来的行相同**的
拒绝路径。

**它证明不了的是**：一行**真正属于别人**的记录会被扣下。那是那个工具自己的行为，在它被测到的地方被测到，
**本页不重新确立它**。把这句话说出来，是「演示」与「主张」的分别。
