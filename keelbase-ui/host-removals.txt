# Paths the product does not ship. The build resets the checkout to upstream and then removes each one,
# and it fails if a path is not there — a path that has disappeared upstream means this list has to be
# revisited, not that the entry should be skipped. Without the reset the list would not be idempotent:
# the files come back every time upstream is refetched.
#
# Every entry is a plain repo-relative path: no leading slash, no `..`. Blank lines and lines starting
# with `#` are ignored.
#
# 本产品不发的路径。构建先把检出复位到上游、再把每一条删掉，且**路径不在就失败**——上游那边消失了，
# 意味着这份清单需要重做，而不是把这一条跳过。没有那道复位，清单就不幂等：上游每重新取一次，文件就回来。
#
# 每条都是**普通的仓内相对路径**：不以 `/` 开头、不含 `..`。空行与 `#` 开头的行忽略。
